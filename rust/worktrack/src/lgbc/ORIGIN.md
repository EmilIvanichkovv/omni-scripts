# Origin of the files in `src/lgbc/`

These files are copied from `rust/local-git-branch-cleanup-tui/` (LGBC), not shared (worktrack spec
section 2.2). Each copied file starts with a header comment that names its source and commit. To
sync a fix in either direction, diff the copy against the source file at the commit below and
reapply the local changes listed here.

Source commit for every file: `7257f76bb3abe5719a52284f2b8d835151f9cb15`.
